# ORGANIX — Screen-by-screen user flow

## Screen 01: LIQUID
Turquoise, evolving nested ripples, wide stereo trails. 12 material parameters; selected A/B information. Default screenshot should resemble the provided LIQUID composition.

## Screen 02: CRYSTAL
Ice blue, polygon facets, translucent harmonic lattice. The sound field must not be identical to LIQUID with a recolor.

## Screen 03: PLASMA
Magenta electric distorted arcs, small discharge flecks, visibly different response for strong transients.

## Screen 04: VAPOR
Violet-blue particles, diffused motion, grain cloud visual language. Grain DSP is currently a bounded real-time prototype.

## Screen 05: METAL
Amber resonant plate/polygon plus hard orbital geometry. Cleaner, more rigid motion than VAPOR.

## Screen 06: LIGHT
Warm champagne-gold central prism/radiating lines. Sound currently a harmonic-exciter prototype, not an STFT spectral resynthesizer.

## State screens
- Layer A / B switches which engine the controls edit; left rail badges show A, B or A+B.
- Bypass changes engaged state and dims active accent without hiding the control.
- Preset selection populates current engine and parameters; modified title/indicator should reflect edits when it is reliably tracked.
- Macro view trades the three bottom default cards for eight macros. Revert returns to default without resetting parameters.

## Resize states
- Reference 1504×1008: full visual, 3×4 property grid and bottom panels visible.
- Compact ~1240×820: maintain minimum knob cell size and readable labels.
- Large 1900×1120: center visual expands; sidebar and property panel sizes capped.
No overlay, off-screen button, cut text or unpredictable empty gap.

## Explicitly not yet screens
A dedicated category/tag/favorite browser, modal physics matrix, XY snapshot quad, trajectory edit page and FFT/spectrogram are planned separate pages, not fake extensions to the home screen.
